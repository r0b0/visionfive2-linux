Unofficial linux kernel debian repository for JH7110

This is an unofficial fork with updated 6.12, tested on VisionFive 2 Lite on Debian 13 Trixie

See the project page for details

Usage

Import the signing key

sudo curl https://r0b0.github.io/visionfive2-linux/pubkey.gpg | sudo gpg -o /etc/apt/trusted.gpg.d/r0b0-visionfive2-linux.pgp --dearmor

Setup the repository

sudo curl https://r0b0.github.io/visionfive2-linux/r0b0-visionfive2-linux.sources -o /etc/apt/sources.list.d/r0b0-visionfive2-linux.sources

Pin the repository

sudo curl https://r0b0.github.io/visionfive2-linux/r0b0-visionfive2-linux.pref -o /etc/apt/preferences.d/r0b0-visionfive2-linux.pref

Update and use

sudo apt update
sudo apt install linux-headers-6.12.88-r0b0-2026-05-14 linux-image-6.12.88-r0b0-2026-05-14 linux-libc-dev
